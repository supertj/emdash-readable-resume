### Why are the dates after a bar instead of on the right margin?

Sandboxed plugins can't add styles to the public site, so the plugin writes plain headings and paragraphs that your theme styles like any other page. The place and dates follow a bar on the same line.

### Will it print as a one-page resume?

Your theme decides how the page prints. The Blog template, for example, prints its header and footer too, so check the print preview. For a one-page PDF, the same layout is the free Classic template for Google Docs and Word on ReadableResume.

### What happens if I edit the page in the editor?

The next save from the Resume page replaces the page's title and content. The slug, SEO fields and publish state are left alone.

### What happens when I uninstall it?

The page stays in Pages as an ordinary page.
